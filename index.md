## What you must have ready before you travel

Day 2 is a hands-on technical day. It only works if you have some kind of functional R code already running when you arrive (even if it is beta/version 0.1.0). Building one from scratch on site is not realistic, and you will not get anything out of the workshop or be able to meaningfully contribute.

  <div class="req-item">

      <p>End to end on your own machine, from input data through to forecast output. It does not need to be elegant yet. But it needs to be able to run.</p>

## Why we are all travelling

At the date of our workshop, the PREDICT project has 18 months left and we have been working remotely so far. These three days exist to produce four things that cannot be produced on a call 
(all with the brilliant, professional support from LWE computing engineers):

1. **Every partner's workflow visible in one place**, in one shared vocabulary, so we can see what overlaps and what is missing.
2. **The shared code components understood and executed**.
3. **All of us working on our projects collectively, at the same time**, feel the group energy and momentum!
4. **A roadmap for the rest of the project**, with the barriers/issues given air time to discuss and overcome together.
